# Version 1 checkpoint fixture

`checkpoint-v1.nnj` was generated by the installed monolithic NNJava artifact before module extraction.
The original producer source is included here. The producer artifact SHA-256 was
`2836024de8013f64c4589a7f2da5b644675cd35470c7a7d4cf717ea7ef1229e5`.

It contains FP32, INT32, BOOL, a tied-weight alias, module counters/configuration,
optimizer slots/counters, and metadata. Compatibility tests read it with the new
model archive and training checkpoint APIs.
